# Project: API Automation with REST Assured and Allure

Проект автоматизированного тестирования REST API с использованием Java, JUnit 4, REST Assured и Allure Report.

## Технологии и зависимости

| Компонент            | Версия |
|----------------------|--------|
| Java                 | 11     |
| Maven                | 3.9+   |
| JUnit                | 4.13.2 |
| REST Assured         | 4.4.0  |
| Allure Framework     | 2.15.0 |
| AspectJ              | 1.9.7  |
| Apache Commons Lang3 | 3.12.0 |
| Gson                 | 2.13.2 |
| Hamcrest             | 2.2    |

## ▶️ Как запустить тесты

Выполните в терминале из корня проекта:

```bash
mvn clean test
mvn allure:serve
